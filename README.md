# 台风救援互助小程序

一个基于微信小程序原生开发与微信云开发的台风灾害互助 MVP。

当前版本聚焦两个能力：

- 救援互助：发布求救信号、查看附近求救、查看详情、电话联系、导航、图片预览与保存。
- 防灾科普：台风前、台风中、台风后、特殊人群和应急包指南。

## 技术栈

- 微信小程序原生开发
- 微信云开发
- 云函数
- 云数据库
- 云存储
- 腾讯地图组件

## 云函数

正式运行前需要在微信开发者工具中上传并部署：

```text
setupDB
publishSOS
nearbySOS
updateSOS
```

部署方式：

```text
右键云函数目录 -> 上传并部署：云端安装依赖
```

首次运行需要执行一次 `setupDB`，用于创建数据库集合。

## 数据集合

- `sos_signals`：求救信号、位置、照片、需求类型、联系电话、状态等。
- `typhoons`：历史遗留集合，目前小程序入口已移除台风追踪模块，可暂不使用。

## 隐私和安全说明

本项目会使用以下用户信息：

- 位置信息：用于发布和查看附近求救信号。
- 联系电话：用于救援人员联系求助者。
- 现场图片：用于说明求救现场情况。
- 相册写入：用于保存求救现场图片。

正式上线前需要在微信公众平台配置隐私保护指引，并增加免责声明、举报和管理员审核机制。

## 免责声明建议

本小程序仅用于民间互助信息发布与防灾科普，不替代 110、119、120 等官方应急救援渠道。遇到生命危险请第一时间拨打官方救援电话。
